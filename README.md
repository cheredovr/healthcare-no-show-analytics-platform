# 🏥 Healthcare No-Show Analytics Platform

> **Аналитическая платформа для прогнозирования неявки пациентов на медицинские приёмы**

## 🎯 Цель проекта

Разработка системы машинного обучения для прогнозирования вероятности неявки пациентов на запланированные медицинские приёмы. Это поможет медицинским учреждениям:

- 📈 Оптимизировать загрузку врачей
- 💰 Снизить финансовые потери от пустых слотов
- ⏰ Улучшить планирование расписания
- 👥 Повысить удовлетворённость пациентов

## 📊 Данные

Используется датасет **Medical Appointment No Shows** из Kaggle, содержащий информацию о:
- Демографических данных пациентов (возраст, пол)
- Характеристиках приёма (дата записи, дата приёма, район)
- Медицинских показателях (диабет, гипертония, алкоголизм и др.)
- Получении SMS-уведомлений
- Участии в программе Bolsa Família (социальная поддержка)

## 🔄 Структура пайплайна

### ЭТАП 1-3: Исследовательский анализ данных (EDA)
- 📋 Анализ качества данных (пропуски, выбросы, типы)
- 📊 Распределение целевой переменной (no-show)
- 🔍 Анализ факторов, влияющих на неявку
- 📈 Корреляционный анализ

### ЭТАП 4: Feature Engineering & Selection
- 🛠️ Создание новых признаков (lead_time_days, day_of_week и др.)
- 📊 Анализ важности признаков
- ✂️ Отбор наиболее значимых переменных

### ЭТАП 5-7: Машинное обучение
- 🎲 Разделение данных (train/test)
- 🤖 Обучение baseline модели (Logistic Regression)
- 📏 Оценка качества (ROC-AUC, Precision, Recall)
- 💾 Сохранение обученной модели

## 🚀 Быстрый старт

1. **Клонирование репозитория:**
```bash
git clone https://github.com/your-repo/healthcare-no-show-analytics-platform.git
cd healthcare-no-show-analytics-platform
```

2. **Установка зависимостей:**
```bash
pip install -r requirements.txt
```

3. **Подготовка данных:**
   - Скачайте датасет [Medical Appointment No Shows](https://www.kaggle.com/datasets/joniarroba/noshowappointments) с Kaggle
   - Поместите файл в `data/raw/medical_appointments_noshow.csv`

4. **Запуск полного пайплайна:**
```bash
python main.py
```

## 🏆 Метрики качества

Основные метрики для оценки модели:
- **ROC-AUC**: Площадь под ROC-кривой
- **Precision**: Точность (из предсказанных no-show, сколько действительно не пришли)
- **Recall**: Полнота (из реальных no-show, сколько мы предсказали)
- **F1-Score**: Гармоническое среднее precision и recall
